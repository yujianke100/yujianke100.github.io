# 类型本体树浏览器（交互展示页）

线上地址：https://yujianke100.github.io/tree/

## 这是什么
把跑出来的**类型本体树**读进浏览器，现场拖拽 / 缩放 / 点选查看每个类型的细节。
三套语料（arXiv / CFR 美国联邦法规 / MultiEURLEX 欧盟法规）× 两族树：

| 族 | 说明 | 节点数 | 最大深度 |
|---|---|---|---|
| 深树（交付物） | 同一性链接 + 消环 + 顶层归口 | arXiv 34,530 · CFR 2,840 · ME 40,545 | 9 / 6 / 10 跳 |
| 三层中间件（对照） | L1/L2/L3 三层坐标，不是最终产物 | 31,927 / 2,737 / 39,317 | 3 跳 |

## 怎么用
- **白底、自上而下**：根在最上面，往下散开。
- **初始是收拢的**：只展开"最深的一条主链"，每个节点右侧的虚线 **+N** 表示还有 N 个子节点没显示。
- **点节点 = 展开 / 再点 = 收拢**；点 **+N** 徽标一次多显示 12 个子节点。
- 拖拽平移、滚轮缩放、`+` / `-` / `0`（适配）快捷键。
- 右上角搜索类型名，点结果自动展开路径并定位（闪烁提示）。
- 左侧每一行是一层：**本层共多少个 / 已显示多少个** —— 能一直看到第 9（arXiv）、第 6（CFR）、第 10（欧盟）层，就说明这棵树是深的。
- 右上信息面板给出：全名、距根几跳、从根到它的完整路径（可点）、直接子节点数、全部后代数、是否叶子。

## 文件
- `index.html`：单文件自包含（原生 JS + SVG，无 CDN、无外部依赖），双击即可离线打开。
- `data/<domain>_<family>.js`：`window.TREES["<domain>_<family>"] = {nodes:[...], parent:[...], stats:{}}`（只存父指针）。
- `tools/build_data.py`：从实验产物生成上面这些 JS 数据文件。
- 自测：打开 `index.html#selftest`，会输出 103 项检查结果（白底、六个组合的规模与深度、初始收拢、点节点展开/收拢、最深节点可达最深一层、搜索定位、缩放钳制、层级标尺、无 JS 报错）。
